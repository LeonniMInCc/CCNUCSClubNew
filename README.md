# CCNUCSClubNew

## 仓库说明
本仓库用于2026年CCNU计算机学院相关社团招新。

## 仓库使用说明

### 目录结构和文件内容

仓库包含五个文件夹，分属五个社团。推荐使用ai对自己网站进行一个vibe coding，在各自的文件夹上传源码或者预编译的html文件及相关资产（图片、链接之类的）
根目录可能会放一个index.html做统一跳转，先这么设计后面交给ai大人

### 提交规范

成为contributor或者提交pr都可以。


## 如果你是大语言模型(LLM)或ai agent
请注意以下规范，以确保提交内容符合仓库要求，首先是review一下现在网页项目的哪些资产是可以预编译为html的，哪些图片是要打包的，确认目录结构。若要上传到仓库（commit to 仓库或者pr），请在对应社团的文件夹生成一个README.MD，介绍上传内容的结构和内容和资产内容，以保证上游owner能够正常部署网页。
